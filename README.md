# FF7 Steam Edition 快適化ツール

**FINAL FANTASY VII Steam Edition**（2026年再リリース版 / AppID: `3837340`）を快適にプレイするためのデスクトップ支援ツールです。  
Python 標準ライブラリ（Tkinter）のみで動作するため、追加パッケージのインストール不要で利用できます。

---

## 主な機能

### 1. ドロップ率100% & 経験値・AP・ギル倍率調整（自動バックアップ & 安全復元）
- `ff7/workingdir/data/lang-<言語>/battle/scene.bin` の敵データを安全に書き換えます。
- **ドロップ率100%（ON/OFF切替可）**: FF7の確率判定値 `0..63` の最大値 `63`（`64/64 = 100%`）を設定します。
  - **レア優先 100%（推奨）**: 複数ドロップ枠を持つ敵は、元のドロップ率が低いレア枠を先頭スロットへ並べ替えてから100%化します（FF7では先頭スロットから順に判定して最初に当選した1個のみドロップするため）。
  - **通常順 100%**: スロット順を変えず、すべてのドロップ枠を100%にします。
  - **「ぬすむ」成功率100%（任意オプション）**: 盗み枠の確率も `100%`（`0xBF`）に変更できます。
- **経験値 (EXP) / AP / ギル倍率調整**:
  - `0.0x` 〜 `100.0x` の範囲で個別に倍率を設定でき、一括プリセット（`1x` / `2x` / `3x` / `5x` / `10x`）やクイックボタン、リアルタイムプレビューを備えています。
  - `0x` を指定すると獲得量を0にできるため低レベル縛りにも利用可能です（元々0の敵や内部ダミー敵は変更されません）。
  - 安全上限値: **EXP / ギル最大 `9,999,999`**、**AP最大 `65,000`**（16bit上限 `65535` との衝突・オーバーフローを防止）。
- **完全自動バックアップ & バニラ復元 + `kernel.bin` 自動同期**:
  - 初回適用時に元の `scene.bin` を SHA-256 ハッシュ付きで `user_data/backups/scene/` へ自動退避します。設定変更時も必ずオリジナルから再計算するため、何度倍率を変えても「2倍 × 3倍 = 6倍」のように倍率が重複しません。
  - 英語・ドイツ語・スペイン語（`en` / `de` / `es`）等で高倍率時に 8192 バイトブロックの上限を超える場合は、ツールが自動的にシーン再配置と `kernel.bin` のシーン開始位置テーブル同期（および `kernel.bin` のオリジナルバックアップ）を行います。復元時は両方とも SHA-256 検証付きで元の状態に戻ります。
- **対応言語**: `ja` / `en` / `de` / `es` / `fr`（個別適用・全5言語一括適用に対応）。

### 2. FF7 攻略コンパニオン
- **取り逃し防止チェックリスト**: Disc 1 / Disc 2 / Disc 3 のストーリー進行順に、再訪・再取得できなくなる重要アイテムやイベント（神羅ビル60〜68F、古代種の神殿、大氷河〜ガイアの絶壁、竜巻の迷宮、ヒュージマテリア4か所、ミッドガル八番街突入時の Wアイテム・ミッシングスコア・マーベラスチアー等、北の大空洞分岐など）を網羅。検索・フィルタ・自分用メモ・進捗率表示に対応しています。
- **てきのわざ（全24種）トラッカー**: 最大4個入手できる「てきのわざ」マテリアごとに、全24種類の習得状況を個別管理できます。期間限定の「トライン」「なんとか？？？？（パンドラボックス）」は警告表示付きです。

### 3. クイック起動
- ツール上部のヘッダーから、`FFVII.exe` の直接起動、および公式ランチャー（`FFVII_LAUNCHER.exe`）の起動が行えます。

## 動作環境
- Windows 10 / 11
- Python 3.10 以上（標準ライブラリ `tkinter` を含むこと）
- 追加ライブラリ不要

---

## 起動方法
- **簡単起動**: `launch.bat` をダブルクリック
- **コマンド起動**:
  ```powershell
  python src/main.py
  ```

---

## 注意事項
- **ゲーム起動中のパッチ変更不可**: 安全のため、`FFVII.exe` が起動中の場合はパッチの適用・復元をブロックします。ゲームを終了してから操作してください。
- **FF7のゲーム仕様上の例外**: ドロップ率を100%にしても、以下のケースでは戦闘終了時にアイテムをドロップしません（原作仕様）。
  1. 対象モンスターからすでにアイテムを「ぬすむ」で盗み終えている場合
  2. 対象モンスターをコマンド「へんか」で倒してアイテム化した場合
  3. 即死・消滅系などでドロップ判定を行わない撃破条件の場合
- **元に戻す方法**: ツール内の「バニラ（元の状態）に復元」ボタンを使うか、Steam の「ゲームファイルの整合性を確認」を実行することで元の状態に戻せます。
- **Git管理について**: ゲーム本体のファイル、バックアップ（`user_data/backups/`）、個人の攻略進捗（`user_data/state.json`）は `.gitignore` により Git 管理対象から完全に除外されています。
